# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Disagreement about design or implementation is welcome; harassment, threats, discrimination, personal attacks, and the publication of another person's private information are not.

Contributors should:

- discuss the work rather than the person;
- give enough context for others to reproduce a problem;
- accept correction and revise claims when evidence changes;
- respect maintainers' decisions about scope, safety, and reviewability;
- avoid spam, deceptive content, and disruptive behavior.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile or another private channel named by the maintainers. Maintainers may edit or remove contributions, lock discussions, issue warnings, or temporarily or permanently restrict participation. Reports will be handled as privately as practical.

This policy applies in repository discussions, pull requests, issues, and other project spaces.
